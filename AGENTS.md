# ChefBot: notes for AI agents (Codex and others)

Read `CLAUDE.md` first: its ground rules apply to every agent, not only Claude (secrets, the public repo, no
emojis, branch + pull request into `main`, never merge). Then `HANDOFF.md`, and `HANDOFF.local.md` if it exists.

Web code (`web/`) is formatted with Prettier 3.3.3: run `npx prettier --write` on changed files (from `web/`)
before committing. CI runs `npx prettier --check .`.
