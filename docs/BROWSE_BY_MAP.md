## What to build

1. **A "Browse by map" button** next to "Browse cuisines" in the "Pick a cuisine" card.
2. **A full-screen map view.** Choosing it replaces the whole screen with the map (not a bottom sheet, no
   other controls) until the user presses Back. The list browser and the rest of the page are hidden while the
   map is open. It must look good and work well on a phone first (about 375 x 812), then desktop.
3. **Drill-down that matches the list browser:**
   - World level: the five continents (Americas, Asia, Europe, Near East, Africa) as tappable regions.
   - Continent level: zoom to that continent; each country or cuisine is a tappable region.
   - Country level (United States, Mexico, Caribbean, China, Japan, India, Italy): zoom in; each regional
     cuisine is a tappable region. "Any" (for example `china_any`) is a plain button on that screen, not a
     map region.
   - Tapping a cuisine opens the same info sheet as the list browser, with its "Pick <cuisine>" button.
     Picking closes the map and returns to the main page with that cuisine selected.
   - Back goes up one level; Back at world level closes the map.
   - Pinch-zoom and pan within a level.
4. **Call-outs for small regions.** Anything too small to tap reliably (aim for at least 44 x 44 px on a phone)
   gets a labelled call-out: a short leader line from the region to a label chip off to the side, and the
   chip is the tap target. Known cases: Palestine and the Levant, Singapore (with Malaysia), Puerto Rico,
   Jamaica, Cuba at world zoom, Cajun vs Creole in Louisiana, Kanto vs Kansai, the Chinese provinces on the
   east coast (Jiangsu, Zhejiang, Fujian, Anhui, Shandong). Work out the rest by testing at phone width.
5. **A small region map in the info sheet.** At the top of the cuisine info sheet (both browsers), show a small
   map with that cuisine's region highlighted. Keep everything else in the sheet exactly as it is, including the
   "If you're missing one" substitutes section.
6. **Tests** in `tests/`: every selectable cuisine (`cuisines.leaves()`, except the `*_any` nodes) and every
   country has a map region; every region id in the map data exists in the cuisine tree; small regions have
   call-outs. Run `.venv/bin/python -m pytest`.

## Map data

Bryan has downloaded the source data, unzipped, into `assets/maps/source/`:

- `ne_10m_admin_0_countries/`: Natural Earth 1:10m country outlines (public domain).
- `ne_10m_admin_1_states_provinces/`: Natural Earth 1:10m states and provinces (public domain). This covers
  US and Mexican states, Chinese provinces, Japanese prefectures, Indian states and Italian provinces (group
  those into regions with the file's `region` field).
- `cb_2023_us_county_500k/`: US Census Bureau county boundaries (public domain), for the Louisiana parishes
  only.

They are shapefiles; read them with a Python library you add to the dev dependencies only (for example
`pyshp`), never to the app's own dependencies. Don't download anything else without asking. Write a build step, `tools/build_map_data.py`, that reads those
files and writes small, simplified map data the app ships (for example `src/chefbot/maps/*.json`): one file per
level, already projected to screen coordinates and simplified so the app stays light on a phone. Commit the
build script and its output, not the raw downloads (add `assets/maps/source/` to `.gitignore`).

Record each source's name, URL and licence in `docs/MAP_SOURCES.md`, and credit them in the README.

## How to draw it in Flet

ChefBot uses Flet 1.0.5. Plain SVG images can't tell you which region was tapped, so draw the regions
yourself:

- `flet.canvas.Canvas` with one `cv.Path` per region, filled and outlined from the theme colours.
- `ft.GestureDetector` around the canvas for taps; find the tapped region with a point-in-polygon test in
  Python (bounding-box check first).
- `ft.InteractiveViewer` for pinch-zoom and pan.
- The call-out chips are ordinary Flet buttons placed with `ft.Stack` over the canvas.

If something here doesn't work in Flet 1.0.5, say so in the pull request and explain what you did instead.
